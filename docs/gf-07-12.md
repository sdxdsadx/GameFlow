# GF-07～GF-12 实施清单

执行顺序：GF-10 → GF-09 → GF-08 → GF-07 → GF-11 → GF-12。

## GF-07：火影忍者可靠性整改与完整验证

- 仅使用 `resources/tools/naruto/MFAAvalonia.exe`，不回退旧影分身。
- 子任务“尝试返回主界面失败”不终止整轮；控制器初始化失败必须终止。
- 决斗场、火影情报社、普通任务静默阈值分别为 1800、900、300 秒。
- 停滞需要同时满足日志、游戏画面和脚本任务状态均无变化。
- MFA 完全退出后才允许修改配置，不在同一步直接重启 MFA。
- 最终验证每日奖励、保存截图并关闭模拟器。

## GF-08：终末地启动与完成判定整改

- 从主机配置读取并启动 `Endfield.exe`，分别等待进程和可见窗口。
- 游戏窗口就绪后启动 MaaEnd，优先使用可访问控件点击开始。
- 完成必须同时具备本轮任务提交、`kind: tasks-completed`、信用点购物完成、获得嵌晶玉 ×200。
- 聚合证据完整时允许单个 task ID 缺失成功事件；明确 `Task.Failed` 仍失败。
- 截图后关闭游戏和 MaaEnd。

## GF-09：QQ 阅读启动、弹窗和动态规划整改

- 使用 MuMu 0 和本轮动态 ADB endpoint，点击开始时自动连接。
- 统一处理安装提示、退出确认、网络重试和常规确认/取消弹窗。
- 奖励页优先扫描，动态规划只执行未完成任务；动态规划保持可选。
- 返回书架失败时恢复并重扫一次；游戏奖励无法识别时记录并继续。
- 每项完成后领奖，最终领取全部奖励并保存代币截图。

- 截图后关闭 MuMu，并确认 Android、播放器和虚拟机 PID 全部退出。

## GF-11：不思议迷宫两轮检查点

- 业务日志 10 分钟无变化时只重启本轮拥有的脚本进程。
- 两轮完成后截图并关闭模拟器，检查点不跨 GameFlow 运行继承。
